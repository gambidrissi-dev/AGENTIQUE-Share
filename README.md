# Agentique

Le terminal macOS pensé pour travailler avec des agents IA — fork non officiel de Zentty (GPL-3.0).

**[Télécharger la dernière version](https://github.com/gambidrissi-dev/AGENTIQUE-Share/releases/latest/download/Agentique.zip)** · macOS 13.0 ou plus récent

Ce dépôt ne contient pas de code : il distribue Agentique. L'app se met à jour toute seule
par [Sparkle](https://sparkle-project.org) depuis [`appcast.xml`](appcast.xml), et chaque archive est signée (EdDSA).

Toutes les apps, et **Vitrine** pour les installer d'un clic : https://gambidrissi-dev.github.io/Vitrine-Share/

Agentique est un fork non officiel de [Zentty](https://github.com/dedene/zentty), distribué sous GPL-3.0 : chaque release joint l'archive des sources correspondantes (`Agentique-<version>-source.tar.gz`).
